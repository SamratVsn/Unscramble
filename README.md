# Unscramble

> A beginner Android learning project exploring ViewModel & App Architecture

A single-player word game that challenges players to unscramble jumbled letters into valid words. Built as part of my journey to understand modern Android development patterns.

---

## 📱 About

**Unscramble** is a simple word puzzle game where players are presented with scrambled letters and must rearrange them to form the correct word. This project served as my introduction to Android's **ViewModel** architecture and state management using **Jetpack Compose**.

---

## 🎯 Learning Objectives

This project helped me understand:

- **ViewModel**: Managing UI-related data in a lifecycle-conscious way
- **App Architecture**: Separating UI logic from business logic
- **Jetpack Compose**: Building modern Android UIs declaratively
- **State Management**: Handling user input and game state updates

---

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Architecture**: ViewModel
- **Build System**: Gradle (Kotlin DSL)

---

## 🚀 Getting Started

### Prerequisites

- Android Studio (latest stable version)
- JDK 8 or higher
- Android SDK

### Installation

1. **Clone the repository**:
```bash
   git clone https://github.com/SamratVsn/Unscramble.git
```

2. **Open in Android Studio**:
   - Launch Android Studio
   - Select "Open an Existing Project"
   - Navigate to the cloned directory

3. **Run the app**:
   - Connect an Android device or start an emulator
   - Click the "Run" button (▶️) in Android Studio

---

## 🎮 How to Play

1. A scrambled word appears on the screen
2. Use all the letters to form the correct word
3. Submit your answer
4. Continue to the next word!
